Introducción

Presentación del Documento

El presente documento hace parte de la evidencia académica GA10-220501097-AA13-EV01, correspondiente a la Actividad de Aprendizaje 13 del Resultado de Aprendizaje GA10, dentro del programa de Tecnología en Análisis y Desarrollo de Software (ADSO) del SENA.

El objetivo central es construir los modelos de acta utilizados al final del proceso de implantación de software: el Acta de Satisfacción del Cliente en el Proceso de Capacitación y el Acta Final de Entrega del Proyecto de Software.

Contexto del Proyecto — DUCTU

DUCTU es una plataforma SaaS (Software as a Service) de gestión académica diseñada para instituciones educativas. Permite la administración estructurada de usuarios, roles, procesos institucionales y comunicación interna mediante una arquitectura modular y escalable.

La plataforma está construida con tecnologías modernas: Next.js (App Router), React, Prisma ORM y PostgreSQL (Neon), aplicando principios de arquitectura limpia y control de acceso basado en roles (RBAC).

Entre los módulos funcionales implementados se encuentran:

  • Panel de administración institucional (Dashboard)
  • Gestión de usuarios con roles: Super Administrador, Administrador, Docente, Estudiante
  • Sistema de calificaciones e importación masiva de notas
  • Calendario académico y gestión de horarios
  • Sistema de publicaciones (Feed institucional)
  • Módulo de notificaciones en tiempo real
  • Configuración académica: años, períodos, cursos, asignaturas y asignaciones docentes

Propósito de las Actas

Al finalizar el proceso de implantación de un sistema de software, es indispensable documentar formalmente tanto la transferencia de conocimiento al cliente (capacitación) como la entrega del producto. Las actas cumplen una función contractual, administrativa y de trazabilidad en el ciclo de vida del software.

Acta N.° 1
Capacitación del Sistema

Registra la sesión de entrenamiento al usuario final: objetivos, temas, responsables y satisfacción obtenida.

Acta N.° 2
Entrega Final del Proyecto

Formaliza la transferencia del producto de software al cliente, con descripción, condiciones y firmas de conformidad.

4. Descripción General del Producto Entregado
DUCTU es una plataforma web SaaS de gestión académica que centraliza los procesos administrativos y pedagógicos de instituciones educativas, con control de acceso basado en roles (RBAC), arquitectura modular escalable e integración con base de datos PostgreSQL en la nube.

4.1 Tecnologías del Sistema

Frontend
Next.js · React · Tailwind CSS
Backend / ORM
Prisma ORM · API Routes Next.js
Base de Datos
PostgreSQL (Neon — Cloud)
